# Codex 维护用途

维护者可以使用 Codex 检查问题复现、实现修复、补充行为测试、审查平台接口契约和整理版本文档。所有修改先经过本机检查，再由维护者决定合并与发布。

拟使用 API 额度的场景包括：拉取请求审查、问题分类建议、回归测试建议、依赖变更说明和发布记录草稿。不得把未核实的模型输出视为平台官方行为、真实付款或真实消息送达的证据。

本仓库不内置 OpenAI 密钥，不自动请求额度，也不在 CI 中调用付费模型。未来接入应使用仓库密钥管理、最小权限和独立审批，避免向模型发送顾客及商家私有信息。

开源支持申请基于真实仓库内容与维护工作，不声称已获得项目支持，也不将商业系统顾客数直接当成代码库的外部采用量。
