# 微信及可选服务接入

## 原生客户端

默认项目使用游客 AppID，并移除了必须先授权的插件声明。`examples/wechat-plugins.json` 仅列出适配层使用的公开提供方标识，不包含插件源码、商家授权或配置密钥。

先运行 `node scripts/configure-miniapp.mjs --api YOUR_API_ORIGIN --appid YOUR_APP_ID`。命令只改当前社区项目的公开客户端配置；不接收 AppSecret 或支付密钥。

需要学生、企微或物流插件时，先在你自己的微信后台添加并授权，再给配置命令加 `--plugins`。该开关将声明及组件引用切换为官方插件，版本可按你的后台许可更新。未启用时使用本地占位组件。

## 服务端

真实服务配置只放忽略的环境文件或部署平台的密钥服务中。可配置项以 `apps/web/lib/config.ts` 的环境声明为准，例如自己的小程序 AppID/AppSecret、商户号、支付密钥、回调地址与公钥。公共仓库不提供这些值。

把本地 API 地址用于开发者工具时，平台可能需要开发环境配置；手机测试和正式部署使用你自己的合法 HTTPS 域名。不要将示例地址误认为可供真实顾客使用的公共服务。

## 权限与结果

- 学生身份由微信提供方核验。商家社媒截图审核与微信学生核验是两个流程。
- 一次性订阅授权和企微客户联系有不同的授权与送达机制。用户点击按钮不能被记作实际消息送达。
- 物流、支付、退款和微信订单管理需要独立平台核验。模拟成功不能当成真实渠道验收。
- 社区奖励与活动默认关闭，由运营者配置并核实成本、有效期和行为证据后启用。

不附带任一现有品牌的小红书账号、企微联系 ID、真实 AppID、商户号、测试会员排除名单或接待员工标识。
